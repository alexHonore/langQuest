Learning curve · teach before testing

Owner feedback from the first iOS simulator pass (2026-10-20): a lesson must not open on a question or a "pronounce this" mic; a beginner needs to meet the language first, with immersion, then practise, with a real progression; and the app needs a place to learn (audio, text, lessons, mini-games) before Missions and Parler. These are declinations for approval — nothing here is built yet.

Reply with one code from each set, e.g. L1 + N2, plus any notes. Built on the approved M3 Melo · C2 cast · U2 Night Market · calm text density. Every mockup fits a 402 × 874 pt phone without scrolling (the fit rule that now ships in the mission player).

Set L · how a lesson teaches before it tests

Today a mission is 8 steps that start with "Que répondriez-vous ?" and a mic. Each option below inserts a discover → practise → use curve; the existing anticipation / choice / speak steps become the practise and use part.

L1

Scene first — watch it happen

The lesson opens on a 20–40 s animated mini-scene: Nadia greets a customer, the line appears in both scripts with the French meaning, Melo points at the one new phrase. The learner taps to replay any line, then shadows it (no score, just "your turn"). Only after 2–3 phrases are met does a question appear.

L2

Audio lesson first — listen, pause, answer

A 2–4 minute narrated mini-lesson (Pimsleur-style): Melo's narrator voice in French introduces each phrase, Nadia says it, a pause invites the learner to say it out loud, then the answer plays. Transcript follows along; hands-free. The quiz steps follow as a short "check".

Set N · where learning lives in the app

Missions and Parler stay. The question is where the learner goes to learn before using it.

N1

An "Apprendre" tab

Five tabs: Accueil · Apprendre · Missions · Parler · Progrès. Apprendre is a unit path (chapter = unit) with lessons (L-format), audio lessons, reading cards and mini-games; finishing a unit's lessons lights up its mission. Home's one action becomes "next lesson" until the mission is ready.

N2

Learning inside each mission (Learn → Practise → Mission)

No new tab. Each mission on the pathway opens to three stops: Apprendre (L-format lesson + cards), S'entraîner (mini-games, audio lesson), Mission (today's spoken steps), then Parler with the mission's character. The pathway stays the single map; the curve is built into every node.
