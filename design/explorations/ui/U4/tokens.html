Line-height is set per script family: Latin 1.3–1.4, Arabic 1.5, CJK 1.45, Devanagari 1.6. Minimum tap target 44 × 44 pt. Text scales with the OS setting up to 200 % — cards grow, nothing truncates except the course name (ellipsis, full name in the accessibility label).

Cards xl, buttons lg, inner media and icon buttons md, chips pill. Nested radius = outer − padding (a 28 px card with 6 px padding holds a 22 px image).

Elevation (clay recipe)

0 · flatpage background, dividers
1 · pressed-ininner highlight 2 px + inner shadow 3 px. Meters, inputs, chips
2 · raised cardinner highlight 2 px, inner shadow 4 px, drop 0 10 24 @ 8 %
3 · floatingprimary mic, sheets. drop 0 14 30 @ 16 %

Dark mode keeps the same geometry but swaps the highlight to 10 % white and the inner shadow to 28 % black; drop shadows go to 30–45 % black. No blur-only shadows: every surface has a visible inner edge so depth survives low-end screens and grayscale.

Motion

idle pulse
Press160 ms · spring cubic-bezier(.34,1.56,.64,1)translateY 3 px + scale .985, inner shadow collapses 4 → 1 px. Buttons, chips, tabs.
Pop in240 ms · same springscale .9 → 1, opacity 0 → 1. Cards appearing, chips, hint sheet.
Settle420 ms · cubic-bezier(.2,.8,.2,1)layout shifts, sheet slide-up, progress meter fill (never spring — meters must not overshoot).
Mic idle pulse1600 ms loop · easescale 1 → 1.06 only when the mic is available. Stops when recording; replaced by a ring that grows with real input level.
Speech bars900 ms loopShown only while character audio is actually playing; a static chip otherwise. Never a decorative waveform.
Celebrate≤ 1200 msMascot bounce (Rive), confetti (Lottie), card pop. Skippable, never blocks the next action.
Reduced motion—All loops off, springs become 120 ms ease, scale changes become opacity-only. Mascot static export.
